개요

구강 스캐너가 만든 3D 메시(PLY · STL · OBJ)와 포인트 클라우드(PLY · PCD · XYZ)를 열어 정점마다 치아 번호나 치은 라벨을 붙이고, 검수를 거쳐 학습 데이터로 내보내는 데스크톱 도구다. 이 문서는 v1 의 화면 목록, 화면별 요소와 동작, 상태와 예외를 정한다. 와이어프레임의 색은 배치와 의미를 보이기 위한 것이고 최종 색 · 서체 · 아이콘은 시안(Skin) 단계에서 정한다.

v1 범위

포함

  • 한 번에 한 턱(상악 또는 하악) 케이스 하나를 연다
  • 메시 PLY · STL · OBJ, 포인트 클라우드 PLY(면 없음) · PCD · XYZ
  • 정점(점) 단위 라벨: FDI 영구치 32개 + 치은(0) + 미분류(−1)
  • 치아 상태(결손 · 임플란트 · 보철 · 부분 맹출 · 과잉치)와 메모
  • AI 자동 분할 결과를 미리 보고 골라 적용 (P1)
  • 공유 폴더 프로젝트, 잠금 파일로 동시 편집 방지
  • 제출 · 검수 · 반려 흐름, 3D 위치에 찍는 검수 의견

제외 (v1 이후)

  • 상 · 하악 동시 표시와 교합 확인
  • 랜드마크(교두 · 접촉점) 라벨, CBCT 볼륨
  • 서버 계정 · 작업 배정 · 통계 대시보드

설계 원칙

  1. 원본은 건드리지 않는다. 스캔 파일은 읽기만 하고, 라벨은 원본을 복사한 <이름>.labeled.ply 의 int fdi · label · instance 필드에 저장한다. 열 때 원본과 정점 수 · 위치가 다르면 알린다.
  2. 손은 마우스와 키보드에 둔다. 라벨은 숫자 두 개(3 6)로, 도구는 글자 하나로 바꾼다. 반복 동작 중 메뉴를 거쳐야만 하는 것은 없다.
  3. 보이는 면만 칠한다. 모든 도구의 기본값은 카메라에서 보이는 정점만 바꾸는 것이다. 뒤쪽까지 바꾸려면 '관통'을 직접 켠다.
  4. 이미 칠한 것을 지킨다. 기본 덮어쓰기 규칙은 '미분류 · 치은만'이고 잠근 라벨은 어떤 도구로도 바뀌지 않는다.
  5. 제출 전에 기계가 먼저 본다. 미분류 정점, 조각난 라벨, 번호 건너뜀을 검사하고 오류가 남아 있으면 제출을 막는다.

공통 규칙

3.1 창 배치

최소 창 크기는 1366 × 768 이다. 작업 화면은 도구 레일(52 px)과 도구 옵션(232 px), 가운데 3D 뷰포트, 오른쪽 패널(320 px)로 나눈다. 도구 옵션과 오른쪽 패널은 각각 Ctrl+[, Ctrl+]로 접고, 경계를 끌어 폭을 바꾼다. 접은 상태와 폭은 사용자 설정에 남는다. 작업 화면은 어두운 테마가 기본이다(메시 셰이딩과 라벨 색이 잘 보인다). 밝은 테마는 시안으로 고를 수 있다.

3.3 라벨 고르기

  • 숫자 두 개: 3 다음 0.8초 안에 6 을 누르면 36 이 활성 라벨이 된다. 첫 숫자를 누르면 뷰포트 위에 3_ 가 뜨고, 시간이 지나거나 없는 번호(예: 39)면 아무것도 바뀌지 않는다.
  • 0 또는 G: 치은. 미분류로 되돌리는 것은 지우개 E 나 Ctrl+드래그로 한다.
  • 클래스: Alt+0 치은 · Alt+1 치아 · Alt+2 스캔바디 (숫자가 파일의 label 값). 숫자 두 개는 지금 클래스의 자리를 고른다. 예: Alt+2 다음 3 6 → 36 자리 스캔바디. 오른쪽 패널의 클래스 버튼도 같다.
  • Tab / Shift+Tab: 아치 순서로 다음 · 이전 치아. 하악은 48 → 41 → 31 → 38, 결손 치아는 건너뛴다.
  • 치식도 칸 클릭, 라벨 목록 행 클릭, Alt+클릭 스포이드.
  • 열린 턱에 없는 번호(하악 케이스에서 11–28)는 고를 수 없다.

3.4 라벨 색

저장 값은 FDI 코드이고 색은 표시용이다. 기본 팔레트는 아치에서 이웃한 두 치아가 색상(hue)으로 확실히 갈리도록 골랐고, 중절치 쌍(11/21, 31/41)도 서로 다른 색 계열이다. 붉은 분홍 계열은 치은에만 쓴다. 스캔바디는 그 자리 치아 색을 옅게 쓰고, 자리가 없으면 금속 회색이다. 미분류는 색을 입히지 않고 원래 셰이딩으로 보인다. 색은 DL-40 에서 바꿀 수 있다.

3.5 표시 모드

메시에는 와이어프레임 모드가 더 있다(면 경계선 위에 라벨 색). Shift+T 로 모드를 차례로 바꾸고 T 로 라벨 색만 켜고 끈다.

라벨 파일 (<이름>.labeled.ply)

  • 원본 스캔은 바꾸지 않는다. 원본의 정점 속성(좌표 · 색 · 법선 등)을 형식 그대로 복사하고 정점마다 int 필드 세 개를 붙인다. 정점 순서는 원본과 같다.
필드뜻값
fdi치아 번호 (치아 · 스캔바디가 놓인 자리)11–48, 자리가 없으면 0
label클래스−1 미분류, 0 치은, 1 치아, 2 스캔바디 (클래스는 앱의 클래스 표에 더할 수 있고, 파일 헤더에 목록을 함께 쓴다)
instance대상 번호치은 · 미분류 0. 칠한 대상(클래스 + 자리)마다 1부터: 클래스 순서, 같은 클래스 안에서는 치식 순서(상악 18 … 28, 하악 48 … 38). 저장할 때마다 다시 매긴다
  • 열 때 scalar_fdi · scalar_label · scalar_instance(CloudCompare 가 붙이는 이름)도 같은 필드로 읽고, 저장은 fdi · label · instance 로 한다. 이전 형식(label 하나에 FDI 번호)도 읽는다.
  • 면은 삼각형으로 쓴다(원본의 다각형 면은 나눈다). 원본의 면 속성과 정점 · 면이 아닌 요소는 옮기지 않는다.
  • 치아 상태 · 메모 · 작업 상태는 헤더 comment 에 쓴다. 공백과 한글은 퍼센트 인코딩한다. 원본 헤더의 comment(스캐너 정보)는 그대로 남긴다.
  • 열 때 원본과 정점 수 · 위치가 같은지 확인하고, 다르면 열지 않는다(DL-90 ④). 원본 SHA-256 은 출처 기록으로만 남긴다.

  • 다른 도구가 원본에 넣어 둔 라벨 필드가 위 규칙에 맞으면 그것으로 시작하고, 아니면 쓰지 않는다.
